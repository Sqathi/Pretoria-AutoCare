## Project Overview

Pretoria AutoCare Detailing is a local automotive detailing business that provides professional vehicle cleaning and detailing services.The purpose of the website is to create an online presence for the business and make iteasier for customers to learn about the services offered.
The website provides information about Pretoria AutoCare Detailing ,its services, and how customers can make enquiries or get in contact with the business.
The website is designed to be simple, clear and easy to navigate.


## Website Goals and Objectives

### Goals

- Create a professional online presence for Pretoria AutoCare Detailing.
- Provide customers with clear information about the business and its services.
- Make it easy for customers to contact the business or make an enquiry.
- Create a simple and user-friendly website that is easy to navigate.

### Objectives

- Develop a multi-page HTML website.
- Provide clear and organised information about the detailing services.
- Include working navigation links between all website pages.
- Include images and relevant content to make the website informative and engaging.
- Test the website to ensure that the pages and navigation work correctly.

## Key Features and Functionality

- Home page introducing Pretoria AutoCare Detailing.
- About Us page providing information about the business.
- Services page describing the detailing services available.
- Enquiry page allowing customers to submit an enquiry.
- Contact page providing contact information for the business.
- Navigation menu linking all five pages together.
- Images used to support the website content.
- Responsive and easy-to-use page layout.
- Clear headings, paragraphs and lists to organise the information.
